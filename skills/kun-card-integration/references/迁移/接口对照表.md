## 易错（迁移必读）

1. `card-recharge-query` **必须按业务拆成两个查单**。  
2. 账户充提 **必须接新查单**（旧无）。  
3. `user-cards` / `card-remark`：`pending_add`，上线前勿编造新 path。  
4. 几乎全部 GET→POST；Body 带 `requestNo` + `secretKey`。  
5. **无双轨期**：切新后以新 API 为准。
