# 迁移分两条线

先看旧 path 前缀，再进对应目录。两条线的对照不能混用。

| 目录 | 旧接口 | 文档状态 |
|------|--------|----------|
| [`vcc/`](vcc/迁移总览.md) | `/rest/v1.0/vcc/*`（商务卡，yeevcc / YOP） | 总览、鉴权、对照表、`mapping.yaml`、能力差异已写。`lookup_mapping.py` **只查本目录** |
| [`caas/`](caas/迁移总览.md) | `/rest/v1.0/caas/*`（消费卡） | 与 VCC 分开。不要读 `vcc/mapping.yaml` |

从零对接、没有旧代码时，不要进本目录。商务卡走 `产品能力/最小跑通.md`，消费卡走 `产品能力/消费卡/消费卡对接.md`。
