# 鉴权迁移：YOP（yop-demo）→ 新开放 API RSA

## 旧侧（对照 yop-demo，勿凭记忆发明）

旧 VCC 经 **YOP** 网关调用，多语言示例仓 **yop-demo** 已覆盖：

| 语言 | 目录 | 关键能力 |
|------|------|----------|
| Java | `java-demo` / `java-demo-without-sdk` / `java-web-demo` | YOP v3 RSA 签名、验签 |
| Python | `python-demo` | `yop_v3_signer`、AES、Webhook HMAC |
| Node.js | `nodejs-demo` | `yopV3Signer.js` |
| TypeScript | `typescript-demo` | 同上 |
| Go | `go-demo` | |
| PHP | `php-demo` | |
| .NET | `dotNet-demo` | |

旧侧常见要素：YOP appKey、商户私钥、UTC 时间戳规范、`x-yop-sign` 响应验签、Webhook **HMAC-SHA256 v1**。细节以客户现网与 yop-demo 源码为准。

## 新侧（opendocs）

| 项 | 值 |
|----|-----|
| 算法 | SHA256withRSA |
| 请求头 | `App-Key` / `Api-Version`（卡接口多为 `2`）/ `Customer-No` / `Timestamp`（毫秒）/ `Sign` |
| 待签 | Body **顶级字段** + `customerNo` + `timestamp`；key **小写** ASCII 排序；**不要**签 `Sign` 自身 |
| Body | `secretKey`（机构业务密钥，≠ RSA 私钥）+ 唯一 `requestNo` |
| 网关 | 沙箱 `https://sandbox.kun.global`；生产 `https://openapi.kun.global` |

联调：`scripts/kun_client.py`；规范：`../平台文档/鉴权认证机制.md`。

## 改造清单

1. 删除/停用 YOP SDK 或自研 YOP 签名客户端对卡接口的调用。  
2. 换成新头签客户端（任意语言，规则同上）。  
3. 所有业务调用改为新 path；GET 改 POST JSON。  
4. Webhook 按新文档验签；授权仍返回 `authResult=A|D` 并幂等。  
5. **无双轨**：生产发布后卡流量只走新网关。
