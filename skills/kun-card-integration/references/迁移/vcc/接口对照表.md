## 易错（迁移必读）

1. `card-recharge-query` **必须按业务拆成两个查单**。  
2. 账户充提 **必须接新查单**（旧无）。  
3. `user-cards` → `userCards`（POST 分页）；勿与 `accountCardInfo`（必填共享账户号）混淆。  
4. `card-remark` → `updateCardRemark`；旧 `remark` 改为 `cardRemark`（覆盖写，空串清空）。  
5. 几乎全部 GET→POST；Body 带 `requestNo` + `secretKey`。  
6. **无双轨期**：切新后以新 API 为准。  
7. `customerId` 在商务卡接口是持卡人 ID，不是旧商户 ID。  
8. `user-info`、`clear-record`、`card-swap` 不是 path 替换，见 [`能力差异.md`](能力差异.md)。
