# CAAS 接口对照表

> 来源：`vcc 新旧接口对照.xlsx` 的 caas sheet。  
> **默认规则**：`POST /rest/v1.0/caas/<后缀>` → `POST /rest/v2.0/caas/<后缀>`，请求和响应字段不变。  
> 开卡、Sumsub、表里「原来没有」的接口见 [`迁移总览.md`](迁移总览.md)，不要按这条规则硬套。

机器可读对照：[`mapping.yaml`](mapping.yaml)。`lookup_mapping.py` 可按旧 path 查本文件对应条目。

## 不要当成默认替换

sheet 后半还把部分卡操作对到了 `/rest/v2.0/api/cardManagement/*` 和 `/rest/v2.0/api/common/*`。  
除总览里的开卡 V2 和「原来没有」的新接口外，迁移不要改走这些路径。
