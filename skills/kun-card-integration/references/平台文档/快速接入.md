## 卡对接最小闭环

**商务卡**：持卡人 → openCard →（充值或共享账户）→ Webhook  
**消费卡**：KYC → apply-card → 充值 → Webhook  
**Webhook**：配置验签密钥 → 异步通知 → 授权决策
